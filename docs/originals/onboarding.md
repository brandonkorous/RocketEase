# Onboarding

## Activation promise

Help a new user reach one meaningful outcome quickly: schedule a real post or handle a real conversation. Setup is resumable, role-aware, and never blocks exploration when sample/demo content can teach safely.

## Core path

1. Create account and verify identity.
2. Create or join an organization.
3. Create a workspace with brand name, timezone, and locale.
4. Choose goals: publish, engage, report, promote, collaborate.
5. Connect at least one social channel and select its workspace assignment.
6. Invite collaborators or skip.
7. Create/import content and schedule the first post.
8. Land on Home with the next best action.

Agency onboarding asks whether to create the first client workspace and establishes visible client naming. Invited users skip organization creation and enter the task they were invited to perform.

## Checklist

Persistent but dismissible:

- Complete workspace profile
- Connect a channel
- Create or import an asset
- Schedule first post
- Invite a teammate
- Configure approvals if relevant
- Review analytics after data arrives

Checklist progress is based on completed domain events, not clicks. Items deep-link to resumable flows.

## Empty states

- No connected accounts: explain value, permission expectations, and “Connect an account.”
- Empty calendar: “Create a post” plus import/duplicate options and an optional short example.
- Empty inbox: distinguish “no messages yet” from unsupported permissions or sync failure.
- No analytics: show connected sources, expected data window, and setup status.
- First campaign: explain how organic content and paid promotion connect; offer a minimal goal-first setup.
- No approvals: explain when approvals help and offer policy setup, not fake queue items.
- Empty library: upload, import from a connected source where supported, or create a template.

Every empty state includes what this area is, why it is empty, one primary action, and a secondary learning path. Never mask an error as emptiness.

## Progressive education

Use contextual tips only after the related surface is encountered. Demonstrate shared versus channel-specific variants in the composer. Explain metric freshness when analytics first appears. Ask before enabling notifications. Do not front-load ads, attribution, or advanced roles for solo users.

## Failure and recovery

OAuth cancellation returns to the exact step with no lost workspace data. Permission shortfalls list affected capabilities. Initial sync can continue in the background. Invitation and publishing failures retain entered data and offer retry. A user can leave and resume from any step.

## Lifecycle communication

In-product notifications are primary. Email is reserved for verification, invitations, approval requests/due reminders, publish failures, security events, scheduled reports, and carefully limited activation reminders. Respect role, workspace, timezone, and notification preferences.

## Measurement

Measure completion and time per step, connection success by provider/error, first-value rate, seven-day activation, checklist completion, invitation acceptance, and drop-off recovery. Segment by persona and acquisition source without collecting unnecessary content.
